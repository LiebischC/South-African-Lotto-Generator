# 🎰 South African Lotto Number Generator

A simple C# console application that generates **6 unique lotto numbers** and a **bonus ball**.  
This project was built to practice the use of the **Random class**, arrays, and basic control flow in C#.

---

## ✨ Features
- Generates 6 unique random numbers between 1 and 49
- Ensures no duplicates in the main draw
- Generates a separate bonus ball (also unique)
- Console-based user interface
- Clear and simple output
